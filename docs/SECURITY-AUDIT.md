# 安全审计（当前轮次）

已处理：

- Flask 本地默认只绑定 `127.0.0.1`；移除通配 CORS。生产模式要求管理员密码哈希、服务端校验密钥，采用 Flask 签名会话 Cookie（HttpOnly/SameSite=Strict/Secure，非服务端持久 Session 存储）；跨站写请求被拒绝。
- Web、CLI、旧发布函数的真实发布闸门默认关闭，模拟 Worker 在独立测试环境运行。
- 网页 Cookie 上传/下载固定拒绝，账号 API 不返回 Cookie 文件名；删除账号改为 DELETE，素材与会话删除前验证路径位于受控目录。
- 第三方头像接口已移除，账号名称不再发送给该接口；Web 小红书二维码不打印终端，临时会话关闭后清理。
- `.gitignore` 与 `.dockerignore` 排除本地数据库、Cookie、素材、备份、密钥和运行日志。离线 `detect-secrets` 扫描当前已跟踪与新增文件均为 0 个未处理命中；已检查 15 个可达提交的敏感文件路径与高置信度密钥特征，未发现命中。此扫描不等于对所有历史内容的数学证明。

仍需处理/复核：

- 其他平台网页登录仍沿用旧流程，断线取消与二维码生命周期未逐一验证。
- 生产口令登录尚无持久化限速/账户锁定；应在 HTTPS 反向代理处添加限流。
- 容器镜像与第三方依赖尚未在本机完成 Docker 构建及漏洞扫描；本机缺少 Docker。
- 旧接口与部分平台适配器仍存在历史日志，需要在开放真实发布前逐项审计，不可将生产日志当作无敏感数据。
- 当前容器示例的本机 HTTP 入口仅用于健康检查；真正的生产登录必须使用 HTTPS 配置。

未删除、重置或导出本机真实小红书 Cookie 与账号数据库；没有执行真实发布。
