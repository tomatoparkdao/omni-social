# 平台上传模块

上传器统一位于 `uploader/`，包括小红书、抖音、快手、B站、视频号/腾讯、百家号、微博、知乎、雪球、TikTok、YouTube、Facebook、Instagram、支付宝和虎扑等目录。具体入口通常为各目录的 `main.py`；登录与视频发布辅助逻辑位于 `myUtils/`。
