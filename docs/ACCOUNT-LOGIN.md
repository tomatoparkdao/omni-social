# 网页账号登录

小红书：账号管理 → 添加账号 → 填写备注 → 确认，前端建立受同源会话保护的 SSE 连接，网页接收二维码数据与最终状态。后端优先校验同名账号已有 Cookie；仍有效时直接返回成功，不覆盖现有会话。二维码仅通过 SSE 发送，Web 模式不向终端打印二维码；临时图片在浏览器任务结束后删除。关闭弹窗会关闭 SSE 并取消小红书扫码轮询；失败或超时可重新获取。

真实扫码只能由账号所有者本人完成。自动化浏览器测试替换 SSE 与账号列表响应，仅使用模拟二维码及模拟账号，不写真实账号数据库。先前真实账号扫码验证记录见 [ACCOUNT-LOGIN-FIX.md](ACCOUNT-LOGIN-FIX.md)；本轮没有要求用户再次扫码，也不能把模拟成功表述为本轮真实授权成功。

小红书以外的平台沿用旧登录适配器；本轮尚未逐个平台验证扫码与断线取消。生产环境必须先完成 HTTPS 和管理员认证配置，不能直接公开 Flask 端口。
