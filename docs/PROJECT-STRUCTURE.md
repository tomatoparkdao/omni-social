# 项目结构

- `sau_backend.py`：Flask Web API，默认端口 5409
- `sau_frontend/`：Vue/Vite 管理界面
- `uploader/`：各平台上传实现
- `sau_commands/`、`sau_cli.py`：CLI
- `db/`：数据库初始化与数据文件
- `myUtils/`、`utils/`：登录、素材与通用工具
- `skills/`：平台运行说明与技能资源
