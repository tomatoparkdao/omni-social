# 本轮开发变更记录

## 未发布：Web 草稿与安全基线

- 保留既有 CLI、Skill、平台上传器及原有账号数据；网页扩充新建任务、发布队列、日历、历史、系统设置与真实任务统计。
- Web 发布中心改为保存草稿，不再用旧接口显示未经证实的“发布成功”；所有真实发布路径默认由统一闸门拒绝。
- SQLite 新增独立 `publish_tasks` 表，提供任务 ID、幂等键、取消和隔离 Mock 状态机；不重建或清空已有账号表。
- 补充四平台 Web/CLI 会话兼容适配与独立真实 Worker 的默认关闭路径；到期任务可原子领取，执行结果不明时保留待核验状态且不自动重试。本轮仅以 Mock 验证该链路。
- 小红书网页扫码增加断线清理、错误终态和现有登录态优先；本轮浏览器测试使用模拟扫码，未要求用户重新登录。
- 生产模式增加管理员口令校验、签名会话 Cookie、同源写请求约束；本地仅绑定回环地址，禁用网页 Cookie 导入导出，并隐藏账号 API 的 Cookie 文件路径。
- 增加 Windows 进程定向启动/停止、前端构建与容器部署草案、数据库备份、单元测试和浏览器 E2E。

未完成项：真实平台执行结果验证、旧 Web 高级参数映射、其余平台 Web 接入、多实例 Worker 互斥、完整组件测试、容器实际构建及 HTTPS 部署验证。详见 [测试报告](TEST-REPORT.md) 与 [平台集成状态](PLATFORM-INTEGRATION.md)。
